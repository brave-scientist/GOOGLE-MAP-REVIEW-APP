All 13 sections verified structurally (tags balanced: 319/319 divs, 10/10 sections, 6/6 articles, 8/8 details, 1/1 table). Pure CSS checkmarks/crosses in comparison table replace inline SVGs to keep payload lean.

**Design approach (3 bullets):**
- **Design-system foundation:** CSS custom-property token layer (`--brass #D6B44F`, `--blue #4464C3`, `--bg #0A0A0B`) drives every surface; three-font stack (Space Grotesk display / Inter body / JetBrains Mono kickers) with strict letter-spacing rules (-2% display, +1.5% uppercase kickers); glassmorphism via `backdrop-filter: blur()` + 8% white borders on every card.
- **Atmospheric depth over flat color:** hero uses three layered systems — a 50px geometric grid with `mask-image` radial fade and 60s drift animation, three floating radial-gradient aurora blobs (brass + blue + emerald) with 18s float cycles, and a brass radial glow behind the H1; product mockup gets its own blue glow and a perspective-tilt that flattens on hover.
- **Interaction choreography over decoration:** every motion is purposeful and accessibility-gated — IntersectionObserver triggers fade-up reveals with staggered delays, stat numbers ease-out count-up only when scrolled into view, magnetic buttons translate toward cursor via `requestAnimationFrame`-driven lerp, custom cursor uses `mix-blend-mode: difference` and expands on interactive hovers, and the entire motion layer is disabled under `prefers-reduced-motion: reduce` while preserving all content visibility.
